# 📊 NTI Advanced Data Analysis — Graduation Project



### *An end-to-end data analysis and machine learning project built as part of the NTI Advanced Data Analysis Course.*

## 📌 Overview

Smart Delivery System is a data-driven project designed to predict whether an order will be delivered on time or delayed.

The project uses data analysis and machine learning to identify factors associated with delivery delays.

It also includes an interactive Power BI dashboard for analyzing delivery patterns and business insights, along with a Streamlit application for presenting the prediction results.

## ❓ Problem Statement

**Business / Research Question:**
Can we predict whether an order will be delivered late based on factors related to the order, customer, and delivery?

**Why this problem matters:**
Delivery delays can negatively affect customer satisfaction, business operations, and delivery costs.

&#x20;Predicting whether an order will be delayed allows businesses to identify potential delays in advance and take proactive actions to improve delivery performance.

**Expected Outcome:**
A machine learning model that can predict whether an order will be delivered on time or delayed, providing useful insights to help businesses identify potential delivery delays and improve delivery operations.
